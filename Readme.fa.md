## پیش‌نیاز

* زبان مجاز: **C#**
* نسخهٔ پیشنهادی: `.NET 6` یا بالاتر
* سیستم‌عامل: آزاد (Windows / Linux / macOS)
* آشنایی با:

  * مفاهیم پایهٔ برنامه‌نویسی
  * ورودی/خروجی در کنسول
  * مدیریت خطا (`try/catch`)

---

## شرح مسئله

برنامه‌ای بنویسید که:

1. دو عدد از کاربر دریافت کند (به‌صورت ورودی کنسولی).
2. عملیات **جمع** را روی آن‌ها انجام دهد.
3. نتیجه را با قالب‌بندی استاندارد در خروجی نمایش دهد.
4. در صورت ورود دادهٔ نامعتبر (مثلاً متن به‌جای عدد) پیغام خطای مناسب چاپ کند.

**هدف:** تمرین مفاهیم پایه‌ای ورودی/خروجی، کنترل خطا، و ساختار کدنویسی تمیز در C#.

---

## قوانین و محدودیت‌ها

* تنها عملیات مجاز: **جمع**
* ورودی باید از طریق **Console.ReadLine()** گرفته شود.
* مدیریت استثناها اجباری است (بدون crash).
* استفاده از کتابخانه‌های خارجی مجاز نیست.
* کد باید قابل اجرا در `.NET 6` باشد.
* کد باید خوانا و مستندسازی‌شده باشد.

## ورودی/خروجی و مثال

**ورودی نمونه:**

```text
Enter first number: 7
Enter second number: 5
```

**خروجی نمونه:**

```text
Result: 12
```

**ورودی نامعتبر:**

```text
Enter first number: abc
```

**خروجی:**

```text
Invalid input! Please enter numeric values only.
```

## نحوهٔ ارسال (PR)

1. ریپو را **Fork** کنید.
2. برنچ جدید بسازید:

   ```bash
   git checkout -b solution/<username>
   ```
3. کد خود را داخل پوشهٔ زیر قرار دهید:

   ```text
   solutions/<username>/
     ├─ Program.cs
     └─ README.md
   ```
4. Pull Request باز کنید با عنوان:

   ```text
   [Solution] ماشین حساب تک‌عملگر - <username>
   ```
